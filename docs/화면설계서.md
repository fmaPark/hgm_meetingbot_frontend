# **1. 개요**

## **1.1. 목적**

본 화면설계서는 HGM\_Workspace의 회의록 관련 최소 MVP 범위의 UI/UX 설계를 체계적으로 정의하고, AI 기반 UI 생성 도구(v0.dev 등)와의 연계를 통해 개발 효율성을 높이는 것을 목표로 한다.

본 문서는 [회의록\_기능명세서\_v1.0.2](https://docs.google.com/spreadsheets/d/12JxxPtO0yPmMj12EIajL0F1ATs_Of7yq_7Dto0qe6fM/edit?usp=sharing) 에 정의된 기능을 대상으로 하며, 화면 구성은 [회의록\_화면정의서](https://docs.google.com/spreadsheets/d/1DLQT5u-C3eFfF2dMRHEOSpakuVbB7YwT_io2_yRMIaE/edit?gid=703416386#gid=703416386) 를 따른다.

## **2.3. 상태 배지**

회의 상태를 시각적으로 구분하기 위한 배지 스타일 정의.

|        |             |            |            |         |          |
| :----: | :---------: | :--------: | :--------: | :-----: | :------: |
| **상태** |    **코드**   |   **배경색**  | **텍스트 색상** | **텍스트** |  **아이콘** |
|   녹음중  |  RECORDING  | Yellow-100 | Yellow-800 |   녹음중   | 🔴 (깜빡임) |
|   대기   |   STOPPED   |  Gray-100  |  Gray-700  |    대기   |     -    |
|  변환완료  | TRANSCRIBED |  Blue-100  |  Blue-800  |   변환완료  |     -    |
|   처리중  |  PROCESSING |  Blue-100  |  Blue-800  |   처리중   |  Spinner |
|  요약완료  |  SUMMARIZED |  Green-100 |  Green-800 |   요약완료  |     ✓    |
|  업로드완료 |   UPLOADED  | Purple-100 | Purple-800 |  업로드완료  |     ✓    |
|   실패   |    FAILED   |   Red-100  |   Red-800  |    실패   |     ⚠    |

- **접근성 규칙**

  - 색상만으로 구분하지 않고 텍스트 필수 병기

  - 아이콘은 보조 수단으로만 사용

## **2.7. 세션 만료 처리**

- **만료 감지 시점**

* API 호출 시 401 응답 수신

* Token Refresh 실패

- **처리 흐름**

|          |                                      |
| -------- | ------------------------------------ |
| **단계**   | **동작**                               |
| 1        | 401 응답 감지                            |
| 2        | Token Refresh 시도 (최대 1회)             |
| 3-A (성공) | 원래 요청 재시도                            |
| 3-B (실패) | 세션 만료 처리 진행                          |
| 4        | localStorage 토큰 정보 삭제                |
| 5        | Toast 표시: "세션이 만료되었습니다. 다시 로그인해주세요." |
| 6        | 로그인 페이지로 리다이렉트                       |

- **미저장 데이터 처리**

  - 세션 만료는 보안 이슈이므로 미저장 데이터 보존보다 즉시 리다이렉트 우선

# **화면설계서: 대시보드**

**■ 개요**

대시보드는 HGM\_Workspace 회의록 서비스의 핵심 화면으로, 사용자가 접근 권한을 가진 회의 기록을 조회하고 관리하는 메인 허브 역할을 한다.

**■ 화면 구성**

|           |              |                              |
| :-------: | ------------ | ---------------------------- |
| **화면 ID** | **화면명**      | **설명**                       |
|  USR-001  | 대시보드 (회의 목록) | 정상 상태의 회의 목록 조회 및 관리         |
|  USR-002  | 대시보드 (휴지통)   | 삭제된 회의 목록 조회 및 복구 (Admin 전용) |
|  USR-003  | 요약 설정 모달     | 회의 요약 옵션 설정 및 실행             |
|  USR-004  | 요약 결과 뷰어     | 요약 결과 조회, 수정, Asana 업로드      |

| API 500 에러 발생   | 500 에러 페이지로 리다이렉트 또는 Toast 처리 (화면별 정책) |
